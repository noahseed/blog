# Site personnel de Sébastien Rondeau Cameira

Développement web, mobile et DevOps. Site réalisé avec Vinext et hébergé sur Sites.

Site public : https://sebastien-rondeau-cameira-perso.nimblefrog2049.chatgpt.site

## Développement

Node.js 22.13 ou ultérieur.

```sh
npm ci
npm run dev
```

## Construction

```sh
npm run build
```

La configuration de publication Sites est conservée dans `.openai/hosting.json`.
